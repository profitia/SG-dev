# SpendGuru Data Runtime Canonical Ownership

## Canonical Repository

`profitia/spendguru`

## Canonical Runtime Path

`runtime/data-runtime`

## Data Runtime Scope

The SpendGuru Data Runtime owns:

- source connectivity
- pipeline execution
- runtime persistence
- dashboard read-model hydration
- forecast-accuracy hydration
- runtime schema ownership

## Root SpendGuru Application Scope

The root SpendGuru application owns:

- read-model consumption
- API
- UI
- dashboard
- future AppShell

## Hard Rule

Executable SpendGuru application and runtime code must remain in
`profitia/spendguru`.

External documentation or development-memory systems are not source
repositories for executable SpendGuru code.
