# Architecture technical laboratory

This CLI proves independent test persistence in the two registered new databases. It stores only synthetic Development probe evidence. It is not a copied SG2/SRM implementation, a public runtime, or a tenant security demonstration.

Use a registered ARCHITECTURE task, full preflight and protected local configuration. `npm run probe -- --consumer SG2 --task-id ARCHITECTURE-... --source-sha <actual 40-character SHA>` selects the SG laboratory; `SRM` selects the SRM laboratory. The connection must match Canon host/database/limited role. Identical replay returns IDEMPOTENT; conflicting evidence is preserved and rejected. Do not supply product or owner connections.

`npm test` performs only synthetic unit checks without database access. Actual database proof is part of E0-A-08.
