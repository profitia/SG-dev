# Controlled source admission pilot

This neutral Architecture laboratory document is the exact source used to verify
the shared Development admission process. It introduces no runtime code, package
dependency, product feature, customer data, infrastructure or deployment.

The acceptance scenario checks that trusted main admits only the independently
approved Git blob and file mode, runs the existing controlled installation and
validation with the job token, and emits an exact-source proof. A changed blob,
expired or revoked admission, foreign owner or protected path must be rejected.

The chat may be local or Cloud. The authorized execution environment remains the
existing SG-dev Shared Development Codespace, with project-specific routing and
continuity. This document itself grants no access or execution authority.
