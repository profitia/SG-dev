## Live corrective — optional observation meaning (2026-11-01)

Clearing the observation-meaning selector represents an unanswered declaration, not an empty enum value. The Smart request builder explicitly projects the wire DTO and omits that empty optional field. It preserves the selected policy, verification state, component identity, purchase date and every other form value. Already-open Smart clients also normalize exactly the empty observation-meaning placeholder to an unanswered declaration at the server contract; null, whitespace and other invalid values stay rejected. No verification is inferred. Legacy journey/1.0.0 is unchanged.

Malformed Smart input returns HTTP 400 with a bounded, closed diagnostic code and optional component ordinal; no received values, token, arbitrary property names or private payload are returned or logged. The host renders an actionable Polish correction, separately from business refusal (422), access loss (401/403), rate limit (429) and infrastructure unavailability. A missing source meaning reaches Smart Preparation and its existing verification/business rules; it is never silently approved.
