# Newsfeed Canon — Source Hub Responsibility Amendment v1.1

**Status: ACTIVE — effective through controlled authority main acceptance.**
Date: 2026-11-03. Owner: Architecture Platform. Supplements the [active Newsfeed v1.0 canon](v1.0-newsfeed-business-and-architecture-canon.md) through separately approved controlled adoption. The base canon exact bytes and scope remain unchanged.

## Minimal clarification

Newsfeed remains an independent reusable capability. It owns user observations/subscriptions, monitoring schedules, publication history, deduplication in each observation context, private notifications and distribution to authorized consumers. The accepted v1 business concept, SG Runtime host responsibility, SRM responsibility and Identity/E1 boundaries are preserved. Newsfeed is not reduced to a UI or replaced by Source Hub.

The [Platform Source Hub v1.0](v1.0-platform-source-hub-business-and-architecture-canon.md), owned by Architecture Platform, owns common external-provider integration and source acquisition: provider authentication/transport, capability catalogue, normalization, provenance, licensed caching and provider usage facts. It does not own Newsfeed's private observations, schedules, contextual deduplication, inbox, recipients or publication decisions.

## Existing connector continuity

The accepted NewsAPI implementation, capability catalogue, live evidence, offline tests, workflow and NewsDiscovery 0.1.0 stay in their current Newsfeed paths. This amendment creates no Hub implementation, copy, adapter migration or breaking contract. Consumers continue to use the existing accepted contract; the future producer boundary needs a separately versioned extraction/adoption plan with parity, negative authorization tests and rollback.

Newsfeed will consume Hub only after exact G1/document adoption, admitted contract/provider/E1/cost/licence and owner-provisioned infrastructure plus a separately authorized runtime task. Procurement Insights independently decides relevance, reports and review; Forecast Core and Benchmark/Macrobond authority stay independent. A Hub architecture proposal neither changes their canons nor blocks an existing accepted frozen evidence pilot.
